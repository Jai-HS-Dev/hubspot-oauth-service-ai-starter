# Support And Maintenance

This is a community guided starter, not official HubSpot support or a finished
production integration. Support is best-effort: no response-time commitment,
service SLA, consulting, implementation support or security audit is included.

## Before Asking

Use [the walkthrough](start-here.md), [recovery steps](troubleshooting.md)
and the selected example README. Check [COMPATIBILITY.md](COMPATIBILITY.md) and
[EVIDENCE.md](EVIDENCE.md) for reviewed versions, known limits and the distinction
between local tests and installed verification. Reviewed on 2026-11-04 does not
mean continuously monitored or automatically compatible with future releases.

## A Useful Public Question

Give the starter version (package.json), Node major version, command name,
operating system, expected result and a small synthetic reproduction. State
whether the result is local, developer-account verified or deployed. Do not paste
credentials, account identifiers, private URLs, customer data, full logs,
environment files or screenshots of CRM records. Never commit filled private plans.

## Security Problems

Follow [SECURITY.md](../SECURITY.md), not a public bug report. Use the repository's
private vulnerability-reporting channel when available. If you cannot find a
private channel, ask the maintainer how to report privately without posting
vulnerability details or secrets. Do not assume a public issue is private.

## Update Expectations

Examples and documentation can change. Review the selected version/commit and its
changes before updating; preserve working app identity, auth and hosting. Re-run
the local checks and obtain separate approval for live changes. No automated
dependency upgrade, deployment or service maintenance is promised by this guide.
