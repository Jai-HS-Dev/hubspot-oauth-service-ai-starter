# Hosting Options

This starter is hosting-neutral.

An AI coding tool can help adapt the same OAuth plan to a backend host such as Cloudflare Workers, Vercel, Railway, Render, AWS, Azure, Google Cloud, or another provider.

For any host, confirm:

- how secrets are stored
- how environment variables are set
- how logs are viewed and retained
- how HTTPS is handled
- how deployment rollback works
- how token storage is protected
