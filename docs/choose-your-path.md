# Choose Your Path

## Path A: Learning Locally

- Use a test HubSpot app.
- Use local `.env` values.
- Use fake records or a test account.
- Do not connect real customer data.

## Path B: Hosted Demo

- Use hosting provider secrets.
- Use a test HubSpot account.
- Add safe logging.
- Validate callback URLs carefully.

## Path C: Real Users

- Review scopes.
- Protect token storage.
- Add uninstall/revocation handling.
- Add monitoring, rate limits, and incident response.
- Review privacy, compliance, and data retention.
